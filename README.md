# Boston Housing — Linear Regression

Projekt przewiduje medianę cen domów (`medv`) na podstawie 13 cech z datasetu Boston Housing.

## Technologie
- Python
- pandas
- matplotlib
- scikit-learn

## Uruchomienie
```bash
pip install -r requirements.txt
```

Następnie otwórz i uruchom `Regression.ipynb`.

## Wyniki
Model: Linear Regression  
Podział danych: 80% trening / 20% test  
Wynik przykładowy: R² około 0.79
